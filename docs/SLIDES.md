# Presentation outline

1. **Problem:** gaali, religion-targeted attacks, mixed scripts and spelling evasion require different evidence.
2. **Research question:** can selective investigation improve moderation at useful coverage?
3. **Data:** HOT and THAR; separate labels, source provenance, grouped splits and annotation limits.
4. **NLP:** trained TF-IDF and XLM-RoBERTa models, class imbalance and calibration.
5. **Agent:** model-directed tools, source-bound evidence, deterministic gates and failure handling.
6. **Live demonstration:** normal comment, targeted insult, obfuscation, counterspeech, missing context and unavailable backend.
7. **Results:** only executed scores; separate benchmark tasks and challenge results.
8. **Limitations:** dataset noise, script shifts, single-author drafts, review rate, runtime costs and deployment gap.
9. **Conclusion:** what the measured experiment supports; remaining tests and extensions.
